## 已踩坑（接手前必读）

- **服务启停纪律：一律走本地 `start-all.bat` / `stop-all.bat`（桌面双击或 cmd 运行），禁止在 AI 会话内手动拉起长驻服务**——工具会话结束会回收服务进程树（实测 Redis/Web 被杀，仅 pg_ctl daemon 化的 PG 幸存）；start-all 已固化「先 stop-all 清场 → 启动 → 健康探测失败即 exit 1」。
- `.bat` 脚本必须 CRLF 换行，LF 会导致 cmd 解析错乱（`unix2dos` 转换）。
- `pg` 包 exports 无 types 入口 → 前端自建 `src/types/pg.d.ts`；Tailwind `@apply` 不支持任意变体 → 响应式用原生 media query。
- 旧版代码（Nov 14 旧口径）整体归档在 `_legacy_20261119/`，只作参考不追踪。
- Git Bash 下 `git show origin/main:file` 需 `MSYS_NO_PATHCONV=1`，否则路径被转换报错。
- **mofcom 站点抓取（TSF/shrzgm）**：站点仅支持 TLSv1.2 + 弱 cipher（AES128-GCM-SHA256），OpenSSL 3.x 默认 SECLEVEL=2 握手失败，需自定义 ssl_context 降 `DEFAULT@SECLEVEL=0`；且环境代理（HTTPS_PROXY 本地代理）对弱 cipher 亦握手失败，须 `trust_env=False` 直连。已固化在 `dq/data/fetchers.py`。mofcom 镜像更新滞后（实测至 2026-04），近月由 `OFFICIAL_TSF_SUPPLEMENT`（央行月度《金融统计数据报告》公布值）补录。
- **金十备源教训（BUG-0001）**：金十 bank_financing 口径并非社融增量（月均 3000 亿 vs 真实万亿级），降级灌入污染 127 期历史信号。纪律：数据源接入先做量级体检，宁可缺数不灌错口径，降级源必须同口径。
- **`python -m dq.cli` 双实例坑（BUG-0004）**：cli.py 以 `__main__` 运行时，`from . import jobs_macro` 会再导入一份独立 dq.cli，注册落在副本里 → 任务注册表必须放独立模块 `dq/registry.py`。
- **web DATE 字段时区坑（BUG-0005）**：pg DATE → JS `toISOString()` 会按 UTC 偏移掉一天（本地 GMT+8），统一用 `fmtDate`（getMonth/getDate 本地取值）。
