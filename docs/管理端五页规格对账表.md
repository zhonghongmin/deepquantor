## 通用实现约束（五页共用）

- 分层 `route → lib → services → DB` 单向；接口统一 `{code, message, data}`；配置/密钥走 env。
- 视觉基线 =《管理端效果图》：区块/顺序/卡片数/期数不可变；断点用 `max-[Npx]:`（≤900 侧栏抽屉+遮罩、≤560 表格堆叠卡），禁用默认 `sm/md/lg` 顶替。
- 示例数据一律视为虚构，不搬进工程；涨跌配色遵循 A 股惯例（涨红跌绿）。
- 页面符合性测试按《需求文档》§11.2 断言（dq-test-skill），与五页同步交付。
